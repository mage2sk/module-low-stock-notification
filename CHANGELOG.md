# Changelog

All notable changes to this extension are documented here. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.1.9] - 2026-10-06

### Changed
- Stock alert dialog form on Hyva and Luma now follows the store form style: Name and Email inputs are 46px tall with a 1px #D4D4D4 border, an 8px radius and a teal focus ring.
- The Notify Me submit button is now the standard primary button: solid teal, white text, 15px/600, 8px radius, no gradient and no shadow, a darker teal on hover, 44px tall (48px on phones).
